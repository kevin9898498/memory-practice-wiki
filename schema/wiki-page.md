# Wiki 頁面範本

新增前先讀根目錄的 [AGENTS.md](../AGENTS.md)。概念頁用 `wiki/<英文小寫連字號檔名>.md`，主張 ID 為永久標識。來源摘要放在 `wiki/sources.md`，一篇原始研究對應一個 `Sn`。

## 概念頁

```markdown
# 概念名稱

用一到兩句說明這頁回答什麼問題。

## 主張與依據

### C09

**小標**

寫一句可獨立核對的主張。

- 類型：定義、研究或應用。
- 情境與限制：說明實驗材料、條件、測量時間或教學示例的適用範圍。
- 依據：[S1](../raw/S1.md)。

## 相關概念

- [間隔學習](spacing.md)
```

`C09` 與 `S1` 是格式示例。新增頁時，替換為實際的主張 ID 及支持該主張的研究。新增概念後，同步連到 [Wiki 索引](../wiki/index.md) 與相關頁面。

## 來源摘要

```markdown
### S6

**作者（年份）｜研究題名**

- 方法：寫明材料、比較條件和測量時點。
- 結果：整理與 Wiki 問題相關的結果。
- 限制：保留影響解讀的研究條件和適用範圍。
- 原始資料：[S6](../raw/S6.md)。
```
