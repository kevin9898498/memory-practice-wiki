# 生成前討論紀錄

2026-11-23（台北時間）。作業允許自選題目。本次先在 Codex 和研究分工中對齊受眾、問題、證據門檻及交付方式，再建立來源筆記和概念頁。這一輪是製作過程的範圍討論。

| 討論事項 | 決定 |
|---|---|
| 主題與受眾 | 間隔學習與提取練習，給初次接觸、想調整複習習慣的大學生。 |
| 教完要會什麼 | 說出「何時複習」與「怎麼複習」的差別，做一次先作答後核對的練習，排出可調整的一週計畫。 |
| 問 Wiki 什麼 | 怎麼分辨兩個概念？延後測驗看到了什麼？答對後要不要再練？答錯後如何核對？怎麼合用兩個方法？ |
| 如何納入資料 | 至少 5 篇原始研究。分別記下實驗做法、結果與適用範圍，用來源 ID 連回原文。 |
| 要避免的推論 | 把一個實驗結果當成人人適用的保證，或把教學示例誤寫成研究測得的最佳天數。 |
| 如何驗收 | 簡報從概念頁選取主張並為各頁保留 Wiki 錨點。用初學任務順序編排，跑一次流程並保留實際產生的檢查結果。 |
